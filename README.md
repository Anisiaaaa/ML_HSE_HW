# Домашние работы по курсу «Машинное обучение»

## Темы

- **Pandas** — обработка, анализ и визуализация табличных данных.
- **Градиентный спуск** — реализация линейной регрессии и методов оптимизации (Gradient Descent, SGD, Momentum, Adam).
- **Feature Engineering** — генерация признаков, обработка категориальных и текстовых данных.
- **Глубокое обучение** — Physics-Informed Neural Networks (PINNs) и сверточные нейронные сети для классификации аудио.
- **Деревья решений** — построение, визуализация и анализ моделей.
- **Градиентный бустинг** — обучение и оценка ансамблевых моделей.
- **Explainable AI (XAI)** — интерпретация моделей с помощью SHAP, LIME, PDP, ALE и Permutation Importance.

## Используемые технологии

Python, NumPy, Pandas, Matplotlib, scikit-learn, PyTorch, NLTK.
